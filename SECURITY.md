# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Please do
not open a public issue.

Triodian's answers for a client's CPS 230 and CPS 234 review are in
[triodian-install/docs/security-answers.md](https://github.com/Triodian/triodian-install/blob/main/docs/security-answers.md).

What Start holds: each prospect's email, name and organisation as they typed them, their answers to the profile
questions and the solution set they were shown. No client engagement data and no member or customer data.
